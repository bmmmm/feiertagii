# Werktags-Feiertage

Interaktive Übersicht der gesetzlichen Feiertage in allen 16 Bundesländern, die auf Montag bis Freitag fallen – 1991 bis 2070.

- Liniendiagramm: Feiertage Mo–Fr (oder aufs Wochenende gefallen) pro Jahr und Land, mit Gesetzesänderungen
- Ab heute: bis wann nur normale Arbeitstage anstehen, nächster freier Werktag
- Länderkarte, Rangliste, Jahresraster, Matrix Feiertag × Land
- Optional: Rosenmontag, Heiligabend, Silvester als frei werten

Eine einzelne statische `index.html`, keine Abhängigkeiten außer Google Fonts. Alle Termine werden im Browser aus den Feiertagsgesetzen berechnet (Osterformel, Stand Oktober 2026). Jahre ab 2027 sind eine Projektion nach heutiger Rechtslage.

Lokal: `index.html` im Browser öffnen.
